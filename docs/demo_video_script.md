# FlowForge — Demo Video Script (5 Minutes)

## Minute 1: Introduction & Dashboard
- **Visual**: Start on the Login page. Log in with `admin@flowforge.com`.
- **Audio**: "Welcome to FlowForge, a powerful platform for workflow automation. After logging in, we land on the Dashboard where we can see real-time stats like active workflows, execution success rates, and recent activity logs."

## Minute 2: Workflow Creation
- **Visual**: Navigate to "Workflows" and click "New Workflow". Name it "Onboarding".
- **Audio**: "Creating a workflow is simple. We define the input schema—in this case, employee details—and then add steps for IT setup and HR notifications."

## Minute 3: Rule Configuration 
- **Visual**: Add a rule to the "IT Setup" step. Condition: `location == 'Remote'`. 
- **Audio**: "The heart of FlowForge is our Rule Engine. Here we define that if an employee is remote, they follow a specific IT path. We support complex Boolean logic and custom functions."

## Minute 4: Execution & Feedback
- **Visual**: Trigger a workflow execution with sample data.
- **Audio**: "Watch as we execute the workflow. The system processes the rules in real-time, logs every decision, and updates its state automatically. You can see the logs at each step for full transparency."

## Minute 5: Conclusion & Technical Highlights
- **Visual**: Quick scroll through Backend code and README.
- **Audio**: "Built with Spring Boot and React, FlowForge is designed for extensibility and scale. All our APIs are fully tested and ready for production deployment. Thank you for watching!"
