# Media Assets

Put your project demonstration video here.

### How to add your video:
1.  Record your walkthrough video (e.g., `demo.mp4`).
2.  Move/Upload the video file to this `media/` folder.
3.  The main `README.md` is already configured to link to a file named `demo.mp4` in this folder. If your filename is different, update the link in the root `README.md`.
